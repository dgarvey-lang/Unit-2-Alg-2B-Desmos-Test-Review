# Unit 2 Alg 2B Desmos Test Review — Quadratics Warm-Up

A 15–20 minute warm-up for the Unit 2 test (Solving Quadratic Equations, Desmos allowed).
Students can work with a partner or on their own.

## What's in it
Four problems, one for each kind of question on the test. The numbers are new, but the steps are the same:
1. **Solve by graphing:** 2x² + 10x + 12 = 0, plus a sketch
2. **Two methods:** x² + 5 = 30
3. **Projectile motion:** a ball thrown from a 48 ft cliff, h = −16t² + 64t + 48
4. **Area:** a garden whose length is 3 more than twice its width, area 189 ft². Students write the length expression and the area equation themselves

## Features
- **Partner mode:** Writer and Coach roles that switch each problem. **Solo mode:** talk-it-through prompts.
- **Desmos built in** next to the problem (split screen), plus a Copy button with each equation ready to paste.
- A built-in **scratch board** with pens, eraser, undo, grid, and a bigger view. Each problem has its own board.
- Instant feedback on common mistakes, hints, and worked solutions after two tries.
- A finish screen with a self-rating for each topic and test reminders.
